IDEA PLANE

15 ITEMS
12

CANON OF DIFFERENTIATION

Definition: A characteristic selected for division should actually differentiate the entities or subjects that are to be separated by it.
Example: If books are to be divided into Indian and British literature, "country/origin" is a differentiating characteristic because it separates the two groups.
13

CANON OF RELEVANCE

Definition: A characteristic used in classification should be relevant to the purpose for which the classification is being made.
Example: In classifying books by subject, subject characteristics are relevant; an unrelated characteristic such as the colour of the book cover would normally be irrelevant.
14

CANON OF ASCERTAINABILITY

Definition: A characteristic selected for classification should be capable of being ascertained or determined reliably for the entities being classified.
Example: If place of publication is used as a characteristic, it should be possible to determine the place from reliable information about the document.
15

CANON OF PERMANENCE

Definition: A characteristic selected for classification should possess sufficient permanence so that it does not become unsuitable merely because of temporary or accidental changes.
Example: A stable subject characteristic is preferable to a temporary feature that may soon cease to be useful for arranging the literature.
16

CANON OF CONCOMITANCE

Definition: Characteristics that are concomitant should not be treated as though they were independent characteristics when their occurrence is necessarily connected.
Example: If the presence of one characteristic necessarily accompanies another in the universe being classified, their treatment should recognize that relationship rather than creating an artificial independent succession.
17

CANON OF RELEVANT SUCCESSION

Definition: Characteristics should occur in a succession that is relevant to the purpose of the classification.
Example: When several characteristics can successively divide a universe, their order should be selected according to their usefulness for the intended classification.
18

CANON OF CONSISTENT SUCCESSION

Definition: The succession of characteristics in the associated scheme should be consistently adhered to as long as there is no change in the purpose of classification.
Example: If a scheme establishes Subject → Place → Time as its succession, the same succession should normally be maintained wherever the same conditions apply.
19

CANON OF EXHAUSTIVENESS

Definition: The classes in an array and the ranked isolates in an array should be totally exhaustive of their respective common immediate universes.
Example: BCI lists special kinds of libraries and then provides a residual class such as "other special kinds of libraries." This ensures that the array covers the universe.
20

CANON OF EXCLUSIVENESS

Definition: The classes in an array should be mutually exclusive so that an entity belonging to one class does not simultaneously belong to another class of the same array on the same basis.
Example: If an array divides books by language into English, French and German, the divisions should not overlap on that same characteristic basis.
21

CANON OF HELPFUL SEQUENCE

Definition: The classes or isolates in an array should be arranged in a sequence that is helpful to the majority of users and serves the purpose of the classification.
Example: Historical subjects may be arranged from earlier to later periods when chronological order is most useful to users.
22

CANON OF CONSISTENT SEQUENCE

Definition: Similar classes or ranked isolates occurring in different arrays should have parallel sequences in all such arrays, unless this conflicts with a more important requirement.
Example: If a set of subjects is arranged in the order Physics → Chemistry → Biology in one relevant array, the corresponding repeated group should follow the same order elsewhere.
23

CANON OF DECREASING EXTENSION

Definition: As one proceeds down a chain from a broader class to its subordinate classes, the extension of the classes should decrease.
Example: ANIMALS ↓ MAMMALS ↓ PRIMATES ↓ HUMAN BEINGS Each successive class covers a smaller universe than the preceding class.
24

CANON OF MODULATION

Definition: The transition from one level of a chain to another should be smooth and logically modulated rather than producing an arbitrary or abrupt structural change.
Example: A class should pass systematically from genus → species → subordinate species rather than jumping without an intelligible relationship.
25

CANON OF SUBORDINATE CLASSES

Definition: A subordinate class should be genuinely subordinate to its immediate parent class and should inherit the defining relationship of that parent.
Example: SCIENCE └── BIOLOGY └── BOTANY Botany is subordinate to Biology, which is subordinate to Science.
26

CANON OF CO-ORDINATE CLASSES

Definition: Co-ordinate classes should be immediate subdivisions of the same parent class and should be formed on the same basis.
Example: SCIENCE ├── PHYSICS ├── CHEMISTRY └── BIOLOGY These are co-ordinate classes because they share the same immediate parent.

VERBAL PLANE

4 ITEMS
27

CANON OF CONTEXT

Definition: The denotation of a term in a classification scheme should be determined in the light of the different classes and the context in which the term occurs.
Example: A word such as "culture" may have different meanings in ordinary language. Its meaning in a classification schedule must be fixed by the context of the classes around it.
28

CANON OF ENUMERATION

Definition: Terms used in the scheme should be sufficiently enumerated or specified so that the intended classes and their meanings can be understood without unnecessary ambiguity.
Example: A schedule should specify what a class term includes when ordinary language would leave its scope uncertain.
29

CANON OF CURRENCY

Definition: The terminology of a classification scheme should use terms that are current and accepted in the subject field.
Example: When a discipline replaces an obsolete term with an accepted modern technical term, the classification terminology should recognize the current usage.
30

CANON OF RETICENCE

Definition: The scheme should avoid unnecessary multiplication of terms and unnecessary verbal detail when the intended meaning can be conveyed adequately without it.
Example: Do not create several unnecessarily different terms for distinctions that do not serve a real classificatory purpose.

NOTATIONAL PLANE

21 ITEMS
31

CANON OF SYNONYM

Definition: The class number of a subject and the isolate number of an isolate idea should each be unique. A subject should have one and only one class number, and an isolate idea one unique isolate number.
Example: UDC has synonymous class numbers, e.g. Statistics applied to education may be represented as 31:37 or 37:31. CC generally avoids such synonyms, although a noted space-isolate exception is discussed.
32

CANON OF HOMONYM

Definition: A class number should represent one and only one subject, and an isolate number should represent one and only one isolate idea.
Example: The same class number should not be used to represent two unrelated subjects.
33

CANON OF RELATIVITY

Definition: The number of digits (or digit-groups treated as one digit) in a class/isolate number should correspond to the order of the subject or isolate idea represented.
Example: A notation representing a second-level subdivision should reflect that second order through the structure of its notation.
34

CANON OF UNIFORMITY

Definition: Similar situations should receive similar forms of notation throughout the scheme.
Example: If a particular type of subdivision is represented by a particular notational device in one part of the scheme, comparable subdivisions should use the same device where practicable.
35

CANON OF HIERARCHY

Definition: The notation should make the hierarchical relationship between a class and its subdivisions intelligible.
Example: 5 └── 51 └── 511 The notation shows successive subdivision.
36

CANON OF NON-HIERARCHY

Definition: A notation may avoid explicitly expressing hierarchy when the requirements of the classification make such a non-hierarchical form desirable.
Example: A notation may represent a facet independently rather than encoding every preceding hierarchical level into the visible number.
37

CANON OF MIXED BASE

Definition: A notational base may use more than one kind of symbol/digit in constructing class numbers.
Example: A notation can employ a combination of numerical and alphabetical symbols when the scheme requires a larger and flexible notational capacity.
38

CANON OF PURE BASE

Definition: A notation may use one kind of basic symbol consistently as its notational base.
Example: A purely numerical notation uses digits as its basic symbols throughout.
39

CANON OF FACETED NOTATION

Definition: The notation should be capable of expressing the separate facets/components of a compound subject and their relationships.
Example: A compound subject can have separate notation for Personality, Matter, Energy, Space and Time facets, with symbols joining them.
40

CANON OF NON-FACETED NOTATION

Definition: The notation may represent classes without separately expressing their facet structure.
Example: An enumerative notation can assign a complete class number to a subject without displaying its individual facets.
41

CANON OF CO-EXTENSIVENESS

Definition: The capacity and structure of notation should correspond appropriately with the classes it represents so that the notation can represent the required universe adequately.
Example: The notation should provide enough capacity to accommodate the subdivisions required by the classification scheme.
42

CANON OF NON-CO-EXTENSIVENESS

Definition: A notation need not have exactly the same structural extent as every possible class structure when practical requirements justify a less extensive representation.
Example: A scheme may deliberately restrict notational capacity in a particular portion when that limitation is acceptable for practical use.
43

CANON OF GENERAL MNEMONICS

Definition: Notation should use mnemonic devices wherever possible so that related subjects have related or memorable notation.
Example: The same notational element can be reused for the same general concept in different parts of the scheme.
44

CANON OF ALPHABETICAL MNEMONICS

Definition: Alphabetic symbols may be used mnemonically so that the initial or associated letters suggest the concept represented.
Example: An alphabetic symbol associated with a subject term can help the classifier recall its meaning.
45

CANON OF SCHEDULED MNEMONICS

Definition: A mnemonic relationship should be deliberately built into the schedule so that the notation recalls the corresponding subject or facet.
Example: A particular symbol can consistently denote the same scheduled facet wherever it occurs.
46

CANON OF SYSTEMATIC MNEMONICS

Definition: Mnemonic devices should operate systematically throughout the classification scheme rather than being isolated coincidences.
Example: The same pattern of notation should recur for corresponding concepts in different classes.
47

CANON OF SEMINAL MNEMONICS

Definition: A notation should contain a mnemonic element capable of generating or suggesting related notational forms for related subjects.
Example: Once a particular symbol establishes the identity of a facet, related compounds can reuse that symbol systematically.
48

CANON OF EXTRAPOLATION IN ARRAY

Definition: The notation should permit new classes to be added at the end of an existing array without disturbing the notation of existing classes.
Example: If A, B and C already exist, a newly emerging subject can be accommodated after C without renumbering A, B and C.
49

CANON OF INTERPOLATION IN ARRAY

Definition: The notation should permit a newly emerging class to be inserted between existing classes without disturbing their established numbers.
Example: If A and C exist and a new subject belongs conceptually between them, notation should allow B-like insertion without renumbering A and C.
50

CANON OF EXTRAPOLATION IN CHAIN

Definition: The notation should permit new subordinate classes to be added at the end of an existing chain without disturbing existing notation.
Example: A new species added under an existing genus should receive a new number without changing the numbers of existing species.
51

CANON OF INTERPOLATION IN CHAIN

Definition: The notation should allow a new subordinate class to be inserted between existing members of a chain without disturbing established notation.
Example: A newly recognized intermediate species should be insertable between two existing subordinate classes.

BOOK CLASSIFICATION

3 ITEMS
52

CANON FOR BOOK NUMBER

Definition: The book number should help distinguish and arrange individual documents that belong to the same ultimate subject class.
Example: Two books classified in exactly the same ultimate subject class may receive different book numbers based on an appropriate characteristic such as author.
53

CANON OF COLLECTION NUMBER

Definition: The collection number should distinguish the collection or location to which a document belongs when such differentiation is required in book classification.
Example: Copies of the same subject document belonging to different library collections may be differentiated by collection notation.
54

CANON OF DISTINCTIVENESS

Definition: The book-classification notation should make individual documents sufficiently distinct from one another for their required arrangement and identification.
Example: If several documents have the same class number, their book numbers should distinguish them sufficiently to produce a useful shelf sequence.
