# S. R. Ranganathan’s Normative Principles

A clean, academic, responsive website presenting **S. R. Ranganathan’s Normative Principles** as an organized hierarchy for study and reference.

## About the Project

This repository organizes the supplied material into a simple web-based structure:

- **Basic Laws**
- **Fundamental Laws**
- **Canons**
  - Idea Plane
  - Verbal Plane
  - Notational Plane
  - Book Classification
- **Helpful Sequence**
- **Postulates & Principles for Facet Sequence**

The project also includes a dedicated **Full Chart** page showing the complete hierarchy from the main topic through divisions, sub-divisions, and the original numbered topics.

## Running the Project

This is a static website. No server or package installation is required.

You can open `index.html` directly in a browser for local viewing.

For GitHub Pages:

1. Create a GitHub repository.
2. Upload all files in this project to the repository root.
3. Go to **Settings → Pages**.
4. Select the appropriate branch (normally `main`) and the root folder.
5. Save the Pages configuration.
6. GitHub will publish the website at the repository's GitHub Pages address.
